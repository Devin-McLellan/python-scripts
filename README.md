# Python Learning Journey

Practice scripts from the **100 Days of Code: The Complete Python Pro Bootcamp** on Udemy.

## Structure

```
python-scripts/
├── 01_Section/   - Printing & basics
├── 02_Section/   - Strings, data types & tip calculator
├── 03_Section/   - Control flow & conditionals
├── 04_Section/   - Randomisation & lists
├── Day_7/        - Hangman game
├── Day_8/        - Caesar cipher
├── Day_9/        - Blind auction
├── Day_10/       - OOP & calculator
├── Day_11/       - Blackjack
└── Day_12/       - Number guessing game
```

## Days

### 01 - Printing & Basics
- Hello World and basic `print()` statements

### 02 - Strings, Data Types & Variables
- String indexing and concatenation
- Working with integers, floats and type conversion
- **Tip Calculator** — splits a bill between people including tip

### 03 - Control Flow & Conditionals
- `if`, `elif`, and `else` statements
- Nested conditions
- Rollercoaster ticket pricing based on height and age

### 04 - Randomisation & Lists
- Python `random` module
- Lists and modules
- **Rock Paper Scissors** game
- Random picker for who pays the bill

### Day 7 - Hangman
- Full hangman game with ASCII art
- Word list and lives tracking

### Day 8 - Caesar Cipher
- Encoding and decoding messages by shifting letters
- Functions with positional and keyword arguments

### Day 9 - Blind Auction
- Dictionary-based bidding system
- Finds the highest bidder from all entries

### Day 10 - OOP & Calculator
- Introduction to Object Oriented Programming
- **Calculator** with add, subtract, multiply and divide

### Day 11 - Blackjack
- Card game built with functions and lists
- Handles ace logic and dealer AI

### Day 12 - Number Guessing Game
- Hard/easy difficulty modes
- Tracks remaining attempts

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
python <script.py>
```
